# 📘 Project Documentation

## 1. About the Project

This is a simple personal website. The website features a clean and elegant design that focuses on simplicity and ease of use, aiming to create a pleasant experience for visitors.

---

## 2. Project Structure

```bash
src/
├── app/
│   ├── layout.js
│   ├── page.js
├── components/
│   ├── Card/
│   │   └── Card.jsx
│   ├── Social/
│   │   └── Social.tsx
```

## 3. Installation and Running the App

```bash
git clone https://github.com/enesoncan/enesoncan.com.git
cd enesoncan.com
npm install
npm run dev
```

App will run at http://localhost:3000

Also check out the live project at the following link;

```bash
https://www.enesoncan.com/
```
